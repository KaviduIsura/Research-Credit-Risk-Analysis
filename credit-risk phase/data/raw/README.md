# Datasets (download the ORIGINALS from UCI; do not use Kaggle mirrors)

Put these two files in THIS folder (data/raw/):

| File to place here | Where to get it |
|---|---|
| `german.data` | https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data  -> "Download", unzip, take `german.data` |
| `default of credit card clients.xls` | https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients  -> "Download", unzip, take the `.xls` file |

Do not rename `german.data`. The Taiwan file name must contain "default" and "credit"; keep the original name.

Citations (for the report):
- Hofmann, H. (1994) Statlog (German Credit Data). UCI Machine Learning Repository.
- Yeh, I-C. and Lien, C-H. (2009) The comparisons of data mining techniques for the predictive accuracy of probability of default of credit card clients. Expert Systems with Applications, 36(2), pp. 2473-2480.
